# Página de Receita

## Sobre o projeto

Uma página web criada para apresentar uma receita de forma organizada e visualmente agradável.

A página terá informações sobre o prato, ingredientes, modo de preparo e outras informações relevantes.

## Objetivo

Praticar a estruturação de páginas utilizando HTML5 e desenvolver uma interface organizada utilizando CSS3.

## O que pretendo colocar

* [ ] Nome da receita
* [ ] Foto do prato
* [ ] Descrição da receita
* [ ] Tempo de preparo
* [ ] Rendimento
* [ ] Lista de ingredientes
* [ ] Modo de preparo
* [ ] Informações adicionais
* [ ] Design responsivo

## Tecnologias

* HTML5
* CSS3

## O que vou praticar

* HTML semântico
* Listas ordenadas e não ordenadas
* Imagens
* Links
* Flexbox
* Box Model
* Tipografia
* Cores
* Espaçamento
* Responsividade

## Estrutura planejada

1. **Cabeçalho** — nome e apresentação da receita
2. **Imagem** — foto do prato
3. **Informações** — tempo de preparo e rendimento
4. **Ingredientes** — ingredientes necessários
5. **Modo de preparo** — passo a passo
6. **Informações adicionais** — dicas e observações
